# RoadSafe 위험도 선정 기준 정리

## 1. 산정 방향

RoadSafe는 단순히 사고 위치를 표시하는 지도가 아니라, 사고 이력과 현재 주행 환경을 결합해 사용자의 현재 위치와 이동 경로 주변 위험도를 설명하는 시스템이다. 위험도는 정적위험도와 실시간위험도로 나누어 계산한다.

## 2. 정적위험도

정적위험도는 과거 사고다발지역 데이터를 기반으로 계산한다. 사고 빈도와 인명피해 심각도를 함께 반영한다. 사상자수는 사망·중상·경상·부상신고 인원이 합산된 값이므로 중복 가산을 피하기 위해 원점수에는 직접 넣지 않고, 세부 피해 정도별 가중치를 적용한다.

```text
사고위험원점수 = 사고건수 × 1 + 사망자수 × 10 + 중상자수 × 5 + 경상자수 × 2 + 부상신고자수 × 1
정적위험점수 = 사고위험원점수를 0~100 범위로 정규화한 값
```

## 3. 동일 사망자수일 때 분리 기준

사망자수가 같은 지점은 아래 순서로 위험점수가 갈린다.

```text
중상자수 → 경상자수 → 부상신고자수 → 사고건수
```

예를 들어 두 지점의 사망자수가 모두 1명이어도, 중상자수와 경상자수가 많은 지점이 더 높은 점수를 받는다. 사망자수, 중상자수, 경상자수, 부상신고자수, 사고건수까지 모두 같으면 데이터상 근거가 동일하므로 같은 위험점수를 부여한다. 억지로 다른 등급을 부여하지 않는 것이 분석적으로 더 타당하다.

## 4. 등급 기준

정규화된 점수는 0~100점으로 변환하고, 25점 단위로 낮음·보통·높음·매우높음 등급을 부여한다.

| 점수 구간 | 등급 | 의미 | 알림 반경 |
|---:|---|---|---:|
| 0~25 | 낮음 | 기본 주의 | 200m |
| 25 초과~50 | 보통 | 주변 확인 필요 | 300m |
| 50 초과~75 | 높음 | 감속 및 주의 필요 | 400m |
| 75 초과~100 | 매우높음 | 적극 경고 필요 | 500m |

## 5. 실시간위험도

실시간위험도는 정적위험점수에 현재 조건을 반영한 보정값을 더해 계산한다.

```text
실시간위험점수 = 정적위험점수 + 기상가중치 + 시간가중치
```

- 기상가중치: 현재 날씨가 비, 눈, 흐림, 강수, 강풍 등 시야·노면 조건에 영향을 줄 때 반영한다.
- 시간가중치: 현재 시간대가 해당 구간의 주의 시간대와 겹칠 때 반영한다.

## 6. 낮음 등급이 보이지 않았던 이유

기존에는 지도 생성 시 `MAP_TOP_N = 500`으로 설정되어 전체 위험구간 중 상위 500개만 지도에 포함되었다. 이 방식은 높은 위험구간만 보여주기 때문에 낮음 등급이 거의 보이지 않는 문제가 있었다.

현재 버전은 `MAP_TOP_N = None`으로 설정하여 전체 위험구간을 지도 데이터에 포함한다. 따라서 낮음, 보통, 높음, 매우높음 등급을 모두 확인할 수 있다.

## 7. 화면 반영 방식

- 지도 원형 색상은 현재 위험등급을 따른다.
- 상세 패널에는 사고건수합, 사망자수합, 중상자수합, 경상자수합, 부상신고자수합을 표시한다.
- GPS 기능은 현재 위치 기준 가까운 위험구간 20개를 계산한다.
- 위치 추적 중 각 구간의 알림반경 안에 들어오면 자동 경고를 표시한다.
- 목적지를 검색하면 현재 위치와 목적지 간 자동차 경로를 분석하고, 경로 주변 위험구간을 별도로 표시한다.
- 음성 경고를 켜면 경로상 위험구간 접근 시 브라우저 음성 합성으로 알림을 출력한다.
