# RoadSafe — 교통사고 위험구간 분석 및 경로 연계형 경고 시스템

사고 이력·기상·돌발상황 데이터를 융합해 위험구간을 산정하고, 지도 확인과 GPS 접근 경고까지 제공하는 교통안전 웹 서비스입니다.

## 작업 정보

| 구분 | 내용 |
|---|---|
| 작업 기간 | 2026.03.09 ~ 2026.06.08 |
| 작업 인원 | 3명 (교내 빅데이터프로젝트 경진대회, 우수상) |
| 내 역할 | **PM**, 데이터 수집·전처리, 위험도 분석, 모델 평가 |
| 작업 툴 | Python, HTML, Open API (Kakao Maps·Kakao Mobility, 기상청, ITS 돌발정보) |

## 작품 소개

전국 교통사고 다발지역 데이터, 시간대별·기상상태별 사고 통계, 현재 기상정보, GPS 위치, 카카오 지도/길찾기 API를 결합해 **위험구간 지도 확인 + 웹 내비게이션형 경로 위험 알림**을 제공합니다. 사고 예측 모델이 아니라 **경로 연계형 경고 시스템**으로 연구 범위를 정했습니다. 선행연구 5편(GIS 핫스팟, 교차로 위험도, 기상 기반 위험도 API, 시공간 예측)을 비교한 뒤의 결정입니다.

## 내가 한 일

- 사고 원본 13,959행(표준데이터 12,780 + 지자체별 660 + 법규위반별 519)을 정제·통합해 **13,935개 위험구간**을 구성했습니다.
- 사고 빈도·인명피해를 가중한 위험원점수를 0~100점으로 정규화해 구간 평균을 내고, 25·50·75점 기준으로 4등급(낮음·보통·높음·매우높음)을 분류했습니다.
- 기상·시간대·돌발상황 가중치로 실시간 점수를 갱신하고, 등급별 알림 반경(200~500m)에 진입하면 화면·음성 경고를 보내도록 구성했습니다.
- 팀 PM으로 일정·역할을 조율하고, 분석 파이프라인과 모델 평가를 정리했습니다.

## 결과

| 항목 | 내용 |
|---|---|
| 출처 편중 | 고위험 87개 구간(높음 68 + 매우높음 19)이 모두 `지자체별 일반사고(660건)` 출처에 집중됨. 구간당 평균 사고건수 21.20건 vs 기타 4.58건. **원인은 추정이며** 출처별 집계 기준 재검토를 제안 |
| 등급 분포 | 낮음 13,634(97.84%), 보통 214, 높음 68, 매우높음 19 → 심한 불균형 |
| 실시간 점수 | 2026.06.10 시점 비교에서 점수 상승 1,517개(10.89%), 등급 상향 23개(0.17%) |
| 모델 성능 해석 | Random Forest 정확도 99.68%, Macro F1 0.9656은 **점수 공식으로 만든 등급을 재현한 성능**입니다. 입력 변수가 점수 공식의 구성 요소라서 실제 사고 예측 성능과는 구분합니다 |
| 후속 | KCI 투고용 논문 원고를 제1저자로 작성·수정 중(미투고) |

## 한계

- 위험점수 가중치(사망 10, 중상 5, 경상 2 등)는 통계 검증 전의 **설계값**입니다.
- 등급의 97.84%가 '낮음'이라 등급 간 비교에는 한계가 있습니다.
- 고위험 구간의 출처 편중은 현상 확인까지만 했고 원인은 입증하지 못했습니다.

## 폴더 구조

```text
main.py            전체 분석 파이프라인 실행
src/               수집·전처리·위험도 산정·모델·지도 생성 코드
data/              raw(원본) / processed(정제 결과)
outputs/           figures(그래프), maps(위험도 지도), models, tables
docs/              risk_score_criteria.md (위험도 산정 기준)
```

## 실행 방법

1. 프로젝트 루트에 `.env`를 만들고 API 키(`KMA_SERVICE_KEY`, `KAKAO_JS_KEY`, `KAKAO_REST_KEY`)를 넣습니다. `.env`는 저장소에 올리지 않습니다(`.gitignore`로 제외).
2. `python main.py`로 분석 파이프라인을 실행하면 위험도 테이블, 그래프, 지도, 모델 결과가 생성됩니다.
3. 실시간 지도 갱신과 웹 서버 실행 순서는 [상세 개발 기록](docs/DEV_README.md)에 있습니다.
