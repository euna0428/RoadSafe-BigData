# RoadSafe — 교통사고 위험구간 분석 및 경로 연계형 실시간 경고 웹서비스

사고 이력·기상·돌발상황 데이터를 합쳐 위험구간을 산정하고, 지도 확인부터 경로 검색, GPS 기반 음성 경고까지 제공하는 교통안전 웹서비스입니다.

## 작업 정보

| 구분 | 내용 |
| --- | --- |
| 작업 기간 | 2026.03.09 ~ 2026.06.08 |
| 작업 인원 | 4명 (교내 빅데이터 경진대회 우수상) |
| 내 역할 | 팀장(PM), 사고 데이터 통합 및 위험 지표 설계, 웹서버·지도·경로 경고 개발 (ChatGPT 협업) |
| 사용 기술 | Python, pandas, scikit-learn, JavaScript, ThreadingHTTPServer, Kakao Maps JS SDK, Kakao Mobility API, Geolocation, Web Speech, Folium |
| 외부 데이터 | 전국교통사고다발지역 표준데이터, 한국도로교통공단 사고다발지역(지자체별·법규위반별), 기상청 API, 돌발상황 정보 API |

## 작품 소개

사고 다발 지역을 알려 주는 기능은 내비게이션에도 있습니다. RoadSafe는 여기에 기상과 돌발상황을 반영한 위험도를 더하고, 사용자가 검색한 경로 위의 위험구간을 골라 접근할 때와 진입할 때 각각 음성으로 알려 줍니다. 사고를 예측하는 모델이 아니라 **경로 연계형 경고 시스템**으로 범위를 정했습니다.

## 내가 한 일

**데이터 통합과 위험도 설계**

- 사고 원천 13,959행(표준데이터 12,780 + 지자체별 660 + 법규위반별 519)을 통합해 위험구간 13,935개를 구성했습니다.
- 위치명만으로 중복을 지우면 서로 다른 사고까지 빠질 수 있어서, 좌표 결측값을 제거한 뒤 사고지역관리번호·사고유형·위치명·위도·경도 5개 컬럼을 복합키로 중복을 제거하고 위치별로 집계했습니다.
- 사고 빈도와 인명피해를 반영한 0~100점 위험점수를 만들고 25·50·75점 기준으로 4개 등급을 나눴습니다. 등급별 알림 반경은 200~500m입니다.

**공공데이터 수집**

- CSV는 cp949 → utf-8-sig → utf-8 순서로 읽고, API 응답은 JSON과 XML을 구분해 파싱했습니다.
- 시간 초과와 연속 실패를 처리하고, 수집 결과가 없으면 기존 CSV를 사용합니다.
- 날씨와 돌발상황(유형별 가중치, 반경 1km)을 반영해 위험도와 지도를 갱신하는 파이프라인을 구성했습니다.

**웹서비스**

- `navigation_server.py`(ThreadingHTTPServer)의 `/api/route`가 Kakao Mobility 경로 좌표를 받아 경로 주변과 목적지 인근 위험구간을 거리 기준으로 골라 JSON으로 돌려줍니다.
- Kakao 지도에 위험구간 마커, 상세 정보, 지역 필터를 올리고 브라우저 GPS를 연결했습니다.
- 현재 위치 기준 주변 위험구간 20개와 경로 검색 결과의 위험구간을 따로 표시합니다.
- 위험구간 접근 시와 진입 시 서로 다른 음성 안내(Web Speech)를 냅니다.
- 경로에서 160m 이상 벗어나면 현재 위치를 출발지로 경로를 다시 요청합니다. 경로 API가 실패하면 직선 경로를 대신 보여줍니다.

**개발 과정**

- 웹서비스는 ChatGPT와 협업해 개발했습니다. 실행 화면을 직접 점검하면서 경고가 한 번만 나오는 문제, 내 위치 기준 위험구간과 경로 위험구간이 섞이는 문제, 백석대 주변 사고구간이 지도에 나오지 않는 문제를 찾아 수정 방향을 정했습니다.
- 경로 재탐색은 이미 등록한 Kakao API로 가능한 범위 안에서만 개발했습니다.

## 결과

| 항목 | 내용 |
| --- | --- |
| 출처 편중 | 고위험 87개 구간(높음 68 + 매우높음 19)이 모두 `지자체별 일반사고(660건)` 출처에 집중됨. 구간당 평균 사고건수 21.20건 vs 기타 4.58건. **원인은 추정 단계**이며 출처별 집계 기준 재검토가 필요함 |
| 등급 분포 | 낮음 13,634(97.84%), 보통 214, 높음 68, 매우높음 19 |
| 모델 성능 해석 | Random Forest 정확도 99.68%는 **점수 공식으로 만든 등급을 재현한 결과**입니다. 입력 변수가 점수 공식의 구성 요소이므로 사고 예측 성능으로 보지 않습니다 |
| 후속 | KCI 투고용 논문 원고 작성 중(미투고) |

## 한계

- 위험점수 가중치(사망 10, 중상 5, 경상 2 등)는 통계 검증 전의 설계값입니다.
- 등급의 97.84%가 ’낮음’이라 등급 간 비교에는 한계가 있습니다.
- 고위험 구간의 출처 편중은 현상 확인까지만 했고 원인은 입증하지 못했습니다.

## 폴더 구조

```
main.py                    전체 분석 파이프라인 실행
src/
  fetch_*.py               공공데이터·기상·돌발상황 수집
  preprocess_*.py          사고·기상 데이터 전처리
  risk_score.py            위험점수 계산
  make_risk_grade.py       위험등급 분류
  merge_features.py        구간 통합, 알림 반경 산정
  update_live_risk.py      실시간 위험도 갱신
  realtime_runner.py       실시간 갱신 실행
  navigation_server.py     경로 검색·위험구간 분석 웹서버
  web/                     지도 화면(HTML, JavaScript)
data/                      raw(원본) / processed(정제 결과)
outputs/                   figures, maps, models, tables
docs/                      위험도 산정 기준, 상세 개발 기록
```

## 실행 방법

1. 프로젝트 루트에 `.env`를 만들고 API 키(`KMA_SERVICE_KEY`, `KAKAO_JS_KEY`, `KAKAO_REST_KEY`)를 넣습니다. `.env`는 저장소에 올리지 않습니다.
2. `python main.py` — 위험도 테이블, 그래프, 지도, 모델 결과 생성
3. `python src/realtime_runner.py` — 기상·돌발상황 반영 실시간 갱신
4. `python src/navigation_server.py` — 웹 서버 실행 후 http://127.0.0.1:8000/ 접속

자세한 순서와 자주 생기는 문제는 상세 개발 기록에 있습니다.
